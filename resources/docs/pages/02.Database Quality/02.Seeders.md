# Seeders

Seeders use Laravel seeders and seeders should use Doctrine ORM.
There are two included fixtures.  To rebuild the
SQLite database, copy `.env.dev` to `.env`, delete the `~/database/database.sqlite` file, and run

```
rm database/database.sqlite
php artisan doctrine:schema:create
php artisan db:seed --class=FakerSeeder
```
